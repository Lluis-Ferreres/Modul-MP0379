# La pila del núvol

### IAAS
El concepte IAAS es troba relacionat amb la infraestructura que es lloga als clients. No tot els contractants de serveis tenen les mateixes necessitats, aleshores s'ofereix el conjunt de maquinari mínim per tal que es pugui gestionar allò que cal realitzar.

En resum, es tracta de dividir el maquinari potent del centre de dades en parts que permetin realitzar les tasques per les quals es lloguen els serveis amb la qualitat suficient. Es tradueix en facilitar els recursos per generar màquines virtuals on es podran executar els sistemes operatius junt amb les connexions i l'espai d'emmagatzematge que cobreixin totes les casuístiques possibles.

- Màquines virtuals
- Emmagatzematge
- Xarxes
- Sistemes operatius

Les empreses poden contractar només el maquinari i posar els recursos de programari per la seva banda o bé agafar el conjunt d'eines desenvolupades pel proveïdor.

Exemples: AWS EC2, Google Compute Engine, Microsoft Azure Virtual Machines
